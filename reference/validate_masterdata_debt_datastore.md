# Validate a `masterdata_debt_datastore` object

This function validates that an object is a valid
`masterdata_debt_datastore` dataset.

## Usage

``` r
validate_masterdata_debt_datastore(data)
```

## Arguments

- data:

  An object (typically a data frame)

## Value

`TRUE` if the object is valid, otherwise an error with a message
explaining the failed assertions
